# TrainCrewHub Next

Next.js rewrite scaffold for TrainCrewHub.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- PostgreSQL
- Drizzle ORM

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```

The current Vite/Supabase app remains untouched in the parent project. This folder is the new migration target.
